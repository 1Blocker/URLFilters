# URLFilters

Each release here offers the Bloom prefilter that 1Blocker builds from upstream
filter lists for Apple's URL filter API, and its complete corresponding source.

- `prefilter.bloom` is the prefilter, licensed under GPLv3 or later.
- `payload.aar` is its complete corresponding source. `BUILD.md` inside it says
  how to rebuild the prefilter. The release's tag holds the same source as
  individual files.
- `legal-notice.txt` names each upstream source and gives its license, the
  modification notices and the license texts.
